# Private resume artifacts

Kept in the repository, deliberately not served.

The site no longer publishes a resume in any form: there is no `/resume` route, no navigation
entry, no download action and no sitemap entry. These files were moved out of `public/` so they
are not reachable by URL either, and the generator that produced them was retired along with the
route it rendered.

They are retained because they are the source of record for a document that may still be sent
privately. Nothing in the build reads them.
