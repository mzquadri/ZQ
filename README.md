# Portfolio Website

Personal portfolio for Mohd Zamin Quadri, built with Next.js, TypeScript,
Tailwind CSS, Framer Motion, and React Three Fiber.

The project section links to public repositories and intentionally describes
their verified scope. Experimental or synthetic-data projects are not presented
as production systems or real-world performance evidence.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Verify a production build

```bash
npm run build
```

## Deployment

The site is configured for Vercel. Production deployment uses `npm run build`.
